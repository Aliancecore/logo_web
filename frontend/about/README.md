# about/ — the about page (`about.html`)

Reorganised into `shared/` + `about/` and regenerated by `build/assemble.py`
into `public/about.html` / `public/css/about.css` / `public/js/about.js`.
`frontend/about.html` (and `css/styles.css`, `js/main.js`) are untouched —
read-only references, not written to by this refactor.

## What's in `about/` vs what's in `shared/`

Checked against `home/` (the finished reference page) and against the other
7 pages' own HTML before writing anything, per `shared/README.md`'s rule.
Almost everything about.html's markup *looks* page-specific at a glance, but
most of its components turned out to already be shared or already laid as
groundwork for this page by whoever built home:

- The hero uses `.hero` (shared/styles/hero.css) plus `.page-hero` (shared/
  styles/page-hero.css — built ahead of time for the 6 inner pages,
  verified it lists about.html among its users).
- "What we do"'s right-hand column is `.assurance.assurance--inline` — the
  exact same reassurance-sentence component as home's, confirmed shared in
  both `shared/README.md`'s "Important finding" and `shared/styles/week.css`'s
  header comment ("`.assurance` is used by home AND about.html").
- The left/right layout of "What we do" and "Clients and marketplace" is
  `.split`/`.split__body` (shared/styles/two-columns.css — also built ahead
  of time, "generic", not yet listed as used by any specific page until now).
- The "Sell on our marketplace" card reuses the pricing-card markup verbatim
  (`.plan`, `.plan__head`, `.plan__name`, `.plan__for`, `.checklist` —
  shared/styles/packages.css), just without a `.plan__price` block.
- `.checklist` (the ticked feature list, no plan card wrapper) is also
  already shared (same file).

What's left as genuinely **about-only**, verified by grepping every one of
the other 7 pages' HTML for each class before writing its CSS (see each
file's own header comment for the exact evidence):

- `about/sections/*.html` — this page's own content (headings, team
  roster, client names, photo).
- `about/styles/team.css` — the team grid (`.team`, `.person*`). No other
  page references these classes.
- `about/styles/clients.css` — the client-name chip list (`.clients`). No
  other page references this class.
- `about/styles/hero-photo.css` — the hero photo sizing (`.hero-photo` and
  children). No other page has a `.hero-photo` element — about.html is the
  only inner page whose hero shows a photo rather than a product mockup.
- `about/styles/promise.css` — one rule, `.assurance--inline`: the tweak
  that lets about.html reuse the shared `.assurance` box without home's
  photos/divider above it.

## Files

- `page.manifest.json` — the single source of truth for this page: title,
  description, active nav link (`about.html` — the one page whose own
  footer link gets `aria-current`, not a header-nav link; see
  `shared/layout/README.md`), and the ordered `sections`/`styles`/`scripts`
  lists `build/assemble.py` assembles.
- `sections/` — this page's body content, one file per `<section>`. See
  `sections/README.md`.
- `styles/` — this page's own (non-shared) CSS. See `styles/README.md`.

## Shared file touched by this page

`shared/head/icon-sprite.html` gained one `<symbol id="i-external">`
(about.html's "Visit the marketplace" link icon — the only one of
about.html's 9 icons not already in that shared file), per that file's own
"ADD the missing symbol, don't fork a page-local sprite" instruction. No
other shared file needed a change: about.html's needs were already either
present in `shared/styles/` or had been laid as groundwork ahead of time
(`page-hero.css`, `two-columns.css`) by whoever built `home/`.

## Regenerating

```sh
python3 frontend/build/assemble.py
```

from the repository root (or any directory — paths are resolved relative to
the script's own location). Regenerates every page that has a
`page.manifest.json`.
