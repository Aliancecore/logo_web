# home/ — the home page (`index.html`)

Proof of concept for the new architecture: this page is fully reorganised
into `shared/` + `home/` and regenerated by `build/assemble.py` into
`public/index.html` / `public/css/index.css` / `public/js/index.js`.
`frontend/index.html` (and `css/styles.css`, `js/main.js`) are untouched —
they remain the live, deployed page until the switch is made manually.

## What's in `home/` vs what's in `shared/`

Reading all 8 original pages (not just `index.html`) while splitting
`css/styles.css` turned out to show that almost everything on this page is
already a shared component — hero, domain search, trust list, services
grid, packages, week timeline, final CTA, footer, header, are all reused by
at least one other page. See `shared/README.md` for the full explanation.

What's left as genuinely **home-only**:

- `home/sections/*.html` — the actual page *content* (this page's own
  headings, copy, and the 3 hand-drawn sample sites). Structure can look
  like another page's; content never moves to `shared/`.
- `home/styles/examples-showcase.css` — the showcase grid layout and the 3
  sample sites' colours/drawings (confirmed unique to this page — see its
  own header comment).
- `home/styles/services.css` — one rule: this page's own top-padding hook
  for its services section (other pages use the generic
  `.section--after-hero` preset instead).
- `home/styles/week-photos.css` — the two Kampala photos beside the
  reassurance sentence (about.html reuses the sentence without photos).

## Files

- `page.manifest.json` — the single source of truth for this page: title,
  description, active nav link, and the ordered list of section/style/script
  files `build/assemble.py` assembles. See its own inline structure and
  `shared/README.md` / `shared/styles/README.md` for why the `"styles"`
  list differs from a plain "home/styles/hero.css, home/styles/services.css…"
  per-section file set — most of those turned out to be shared, not
  home-only.
- `sections/` — this page's body content, one file per `<section>`. See
  `sections/README.md`.
- `styles/` — this page's own (non-shared) CSS. See `styles/README.md`.

## Regenerating

```sh
python3 frontend/build/assemble.py
```

from the repository root (or any directory — paths are resolved relative to
the script's own location). Regenerates every page that has a
`page.manifest.json` (today: just this one), writing into `frontend/public/`.
