# website-design/ — the website design page (`website-design.html`)

Reorganised into `shared/` + `website-design/` and regenerated by
`build/assemble.py` into `public/website-design.html` /
`public/css/website-design.css` / `public/js/website-design.js`.
`frontend/website-design.html` (and `css/styles.css`, `js/main.js`) are
untouched — they remain the live, deployed page until the switch is made
manually. Built against `frontend/home/` as the verified reference for
conventions (manifest shape, file naming, comment depth).

## What's in `website-design/` vs what's in `shared/`

This page reuses almost everything already built for home plus a large
amount of "inner page" infrastructure other pages' agents prepared ahead of
time (page hero, name field, price list, FAQ, two-columns, week timeline) —
see `shared/README.md` and `shared/styles/README.md`'s "Created now, not
yet used by home" table. What's left as genuinely **website-design-only**:

- `website-design/sections/*.html` — the page's own content: its hero copy,
  the "what's included" checklist text, the 24 real client sites (names,
  sectors, URLs), the 6 design-price rows, the week/FAQ/CTA copy.
- `website-design/styles/hero-specimen.css` — the hero specimen's "your
  business" colour variant and content (`.site--yours`, `.site__mark`,
  `.yours__*`). Confirmed unique to this page (verified: no other of the 8
  original pages references these classes).
- `website-design/styles/portfolio-sites.css` — the sector filter chips row
  and the 24-card site grid (`.filters`, `.sites`, `.sitecard*`). Confirmed
  unique to this page — this was the one item left "unsure, leave
  untouched" in `shared/README.md`'s original brief, now resolved.
- `website-design/scripts/sector-filter.js` — the sector-filter behaviour
  (extracted from `js/main.js` lines 386-413). Used only here; see
  `scripts/README.md` and `shared/scripts/README.md`'s "Not created yet"
  note for why this stays page-local instead of moving to `shared/scripts/`.

## Promoted to `shared/` while building this page

Two things this page needs turned out to already be shared with other
pages, and were moved to `shared/styles/` instead of being duplicated here
(with a proof comment in each file — see `shared/styles/README.md`):

- **`.blue-tld`** (colours a domain's `.com`/`.co.ug` suffix blue) — found
  living inside what was otherwise hosting.html's own CSS zone in the
  original stylesheet (line ~3225), but also used verbatim by
  hosting.html, digital-marketing.html and email.html. Moved into
  `shared/styles/utilities.css`.
- **`i-external` / `i-edit`** (SVG icon symbols this page's "Sites we have
  built" cards and name field use) — both were already present in
  `shared/head/icon-sprite.html` by the time this page was built (added by
  the agents building about.html/hosting.html/digital-marketing.html for
  their own, identical, icons); this page's manifest just reuses them, and
  the sprite's own comment was updated to record that a third/fourth page
  now depends on each. No sprite edit beyond that comment was needed.

## Files

- `page.manifest.json` — the single source of truth for this page: title,
  description, active nav link, and the ordered list of section/style/script
  files `build/assemble.py` assembles. The `"styles"` order follows "load in
  the order first needed" rather than the page's own section order in one
  place: `shared/styles/packages.css` (for `.checklist`, needed by the
  "What is included" section) is listed before `shared/styles/two-columns.css`
  (for `.checklist--cols`, same section) even though the "Design prices"
  section that *visually* introduces packages/currency comes later — see
  `shared/styles/two-columns.css`'s own header comment: both files style
  `.checklist` at equal specificity, and `packages.css`'s base rule must
  load first for `two-columns.css`'s modifier to win, exactly as in the
  original single stylesheet (packages zone before two-columns zone).
- `sections/` — this page's body content, one file per `<section>`. See
  `sections/README.md`.
- `styles/` — this page's own (non-shared) CSS. See `styles/README.md`.
- `scripts/` — this page's own (non-shared) JS. See `scripts/README.md`.

## Regenerating

```sh
python3 frontend/build/assemble.py
```

from the repository root (or any directory — paths are resolved relative to
the script's own location). Regenerates every page that has a
`page.manifest.json`.
