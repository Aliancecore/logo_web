# hosting/ — the managed-hosting page (`hosting.html`)

Second page reorganised into `shared/` + `hosting/` and regenerated by
`build/assemble.py` into `public/hosting.html` / `public/css/hosting.css` /
`public/js/hosting.js`, following the `home/` page's architecture exactly.
`frontend/hosting.html` (and `css/styles.css`, `js/main.js`) are untouched —
they remain the live, deployed page until the switch is made manually.

## What's in `hosting/` vs what's in `shared/`

Reading hosting.html against the other 7 original pages while splitting
its CSS confirmed that almost everything on this page is already a shared
component: the page hero layout, the standalone name field, the services
card grid (non-linking variant), the packages/currency toggle, the price
list, the FAQ, the final CTA, the footer, the header, the generic
specimen wrapper, are all reused by at least one other page. See
`shared/README.md` and `shared/styles/README.md` for the full picture.

What's left as genuinely **hosting-only**:

- `hosting/sections/*.html` — the actual page *content* (this page's own
  headings, copy, and its hosting control-panel specimen). Structure can
  look like another page's; content never moves to `shared/`.
- `hosting/styles/specimen-hosting-panel.css` — the hosting control-panel
  mockup (`.console`, `.status`, `.bars`), confirmed unique to this page
  (see its own header comment for the grep evidence against the other 7
  original pages).

One finding made while building this page: `.blue-tld` (colours a domain
ending blue inside a specimen) physically lived right next to the console
panel's CSS in the original `css/styles.css`, which made it look
hosting-only at a glance. Grepping `class="blue-tld"` across all 8
original pages showed it is **also** used by website-design.html,
email.html and digital-marketing.html — so it is not in
`hosting/styles/`, it has been promoted to
`shared/styles/specimen-shell.css` (see that file's own header comment).

## Files

- `page.manifest.json` — the single source of truth for this page: title,
  description, active nav link, and the ordered list of section/style/script
  files `build/assemble.py` assembles. Most of the `"styles"` list is
  `shared/styles/*` files already written for the other inner pages
  (see `shared/styles/README.md`'s "Created now, not yet used by home"
  table) plus a few from the table used by home itself; only
  `hosting/styles/specimen-hosting-panel.css` is this page's own.
  Unlike home, hosting has no 3D tilt stage and no domain-search form of
  its own, so `shared/styles/tilt-3d-stage.css`, `trust-list.css` and
  `shared/scripts/tilt-3d.js` are not listed (`shared/styles/domain-search.css`
  *is* still listed, for the `.search__field`/`.search__input` base rules
  the standalone name field reuses).
- `sections/` — this page's body content, one file per `<section>`. See
  `sections/README.md`.
- `styles/` — this page's own (non-shared) CSS. See `styles/README.md`.

## Regenerating

```sh
python3 frontend/build/assemble.py
```

from the repository root (or any directory — paths are resolved relative to
the script's own location). Regenerates every page that has a
`page.manifest.json`.
