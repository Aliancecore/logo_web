# logo-design/ — the logo design page (`logo-design.html`)

Reorganised into `shared/` + `logo-design/` and regenerated by
`build/assemble.py` into `public/logo-design.html` /
`public/css/logo-design.css` / `public/js/logo-design.js`, following the
pattern set by `home/` (see `home/README.md`). `frontend/logo-design.html`
(and `css/styles.css`, `js/main.js`) are untouched — they remain the live,
deployed page until the switch is made manually.

## What's in `logo-design/` vs what's in `shared/`

Most of this page turned out to already be shared with the other 7 pages
once checked: the page hero layout, the specimen wrapper, the process
timeline, the pricing packages chrome, the price list, the FAQ list and the
final CTA are all reused elsewhere. See `shared/README.md` and
`shared/styles/README.md` for the general picture.

What's left as genuinely **logo-design-only**:

- `logo-design/sections/*.html` — the page's own content (headings, copy,
  the Nakato Prints specimen, the 3 logo-style cards, the 7-row file list).
- `logo-design/styles/page-hero-specimen.css` — the hero specimen chrome:
  a shop sign, a one-colour receipt and a round profile picture, built from
  `.signage`/`.lockup`/`.board`/`.receipt*`/`.profile*`. Confirmed unique
  (no other of the 8 original pages uses these classes).
- `logo-design/styles/three-logo-styles.css` — the "Three styles, three
  businesses" card grid (`.logos`, `.logo-card*`, `.emblem`, `.wordmark*`).
  Confirmed unique.
- `logo-design/styles/delivered-files.css` — the "Every file you will be
  asked for" list (`.files`, `.file*`). Confirmed unique.

## Two things this page needed that weren't shared yet

While building this page, two pieces of CSS turned out to already be shared
with another page (or needed to be, to avoid creating a second copy) but
were not yet factored out:

- **`.print` / `.print--rings`** (the wax-print swatch used behind the
  hero's profile-picture avatar) is also used, verbatim, by `index.html`'s
  "Examples" showcase (its fabric-shop swatches) — it lived in
  `home/styles/examples-showcase.css`, documented there as home-only, which
  undercounted it the same way the original zone-by-zone brief undercounted
  several other components (see `shared/README.md`'s "Important finding").
  Promoted to `shared/styles/print-pattern.css` (just the 2 rules this page
  needs; the other 3 `.print--*` variants and the `.shop__item`/
  `.shop__swatches` wrapper overrides stay home-only). **Not fully
  resolved**: `home/` was out of scope to edit for this task, so
  `home/styles/examples-showcase.css` still carries its own copy of these 2
  rules and `home/page.manifest.json` still points at that copy, not at the
  new shared file. See `shared/styles/print-pattern.css`'s own header
  comment and `shared/styles/README.md`.
- **The `<480px` full-width rule for `.hero__actions`/`.btn`** lived in
  `css/styles.css` far from `.hero__actions`'s own rule (grouped instead
  with unrelated mobile tweaks for `.mail__card` and this page's own
  `.signage`/`.receipt`, under a "Motion on inner pages" comment). Since
  `.hero__actions` is already shared via `shared/styles/page-hero.css`, the
  rule was added to that file instead of duplicated here. The `.signage`/
  `.receipt` mobile tweaks from that same block, which are genuinely
  logo-design-only, were consolidated into
  `logo-design/styles/page-hero-specimen.css` instead.
